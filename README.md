# Hitesh Jogeshwari — Portfolio

Personal portfolio for selected software, web and game-development projects.

**Live website:** https://hitesh-jogeshwari-portfolio.vercel.app/  
**Source:** https://github.com/hanisnaff/Portfolio

## Overview

A responsive, editorial-style portfolio built with semantic HTML, CSS and JavaScript. The visual system uses warm grey, off-white, charcoal and muted mineral tones, with responsive layouts and restrained motion.

## Run locally

Open `index.html` in a browser or run:

```bash
npx serve .
```

## Project structure

- `index.html` — page content and semantic structure
- `styles.css` — responsive layout, typography and visual system
- `script.js` — navigation and interaction behaviour
- Portrait image — embedded as an optimized WebP data URI in `index.html` so it loads without a separate asset request
