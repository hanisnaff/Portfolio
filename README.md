# Hitesh Jogeshwari — Portfolio

Responsive editorial-style personal portfolio built with plain HTML, CSS and JavaScript.

## Run locally

Open `index.html` in a browser or run `npx serve .` from the repository root.

## Project content

Project descriptions are based on the corresponding public GitHub repository READMEs. The portrait in `assets/portrait.jpg` was supplied by the site owner. Project artwork is illustrative and should be replaced with actual application screenshots when they are available.
